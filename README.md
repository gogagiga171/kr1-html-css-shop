# Instrumental — магазин инструментов

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер из корня каталога:
`python -m http.server 8000`

## Страницы
- `index.html` — главная страница и популярные товары.
- `catalog.html` — каталог с фильтрами.
- `product.html?name=...` — карточка товара и отзывы.
- `contacts.html` — контактная информация.
- `faq.html` — поиск и фильтрация часто задаваемых вопросов.

## Структура
- `css/style.css` — общие стили и адаптивная тема.
- `assets/screw.svg` — SVG-иконка кнопки прокрутки наверх.
- `js/products.js` — список товаров и категорий.
- `js/home.js` — популярные товары на главной.
- `js/catalog.js` — фильтрация и вывод каталога.
- `js/product.js` — карточка товара и отзывы.
- `js/order-form.js` — форма заявки.
- `js/faq.js` — поиск и фильтрация FAQ.
- `js/to-top.js` — прокрутка к верхней панели.

Отзывы хранятся в `localStorage` браузера. Для приёма заявок и обработки заказов требуется подключение серверной части.
