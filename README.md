# ShopProject — интернет-магазин инструментов

## Запуск
Откройте `index.html` в браузере или запустите локальный сервер из корня проекта:
`python -m http.server 8000`

## Страницы
- `index.html` — главная и подборка популярных товаров.
- `catalog.html` — каталог с фильтрами по категории, цене и подборкам.
- `product.html?name=...` — карточка товара и отзывы.
- `contacts.html` — контакты учебного проекта.
- `faq.html` — поиск и фильтрация часто задаваемых вопросов.

## Структура
- `css/style.css` — общая тема и адаптивные стили.
- `js/products.js` — единый список товаров и категорий.
- `js/home.js` — отрисовка популярных товаров на главной.
- `js/catalog.js` — фильтрация и вывод каталога.
- `js/product.js` — карточка товара и локальные отзывы.
- `js/order-form.js` — модальная форма заявки.
- `js/faq.js` — поиск и фильтрация FAQ.

## Примечание
Это frontend-демонстрация. Заявки не отправляются на сервер, отзывы сохраняются только в `localStorage` текущего браузера. Подборка популярных товаров задана флагом `popular` в `js/products.js` и является редакционной подборкой, а не статистикой реальных продаж.
